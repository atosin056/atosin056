I'm Oluwatosin Akinfenwa. I got into development by building things and gradually expanding what I could build, picking up new skills as each project demanded them.

My foundation is in HTML, CSS, JavaScript, PHP, MySQL, and Bootstrap. From there I moved into React, React Native, and backend/API work with Node.js and Express. Building more complete applications eventually pulled me toward AI, not adding a chatbot for its own sake, but figuring out how retrieval, embeddings, and LLMs can make a system genuinely more useful. That curiosity led me into RAG pipelines, vector databases, and Gemini/Google GenAI integrations. These days I'm spending more time in Python, data science, and NLP, because I want to understand the modeling and data side of these systems, not just call an API.

## 🔧 What I Build

I'm most interested in taking a real problem and turning it into something people could actually use, not isolated tutorial projects. A lot of my recent work sits at the intersection of conventional software engineering and AI: normal web/backend systems where retrieval or an LLM is doing real work inside the product, rather than being bolted on.

I'm also drawn to problems involving trust, verification, and decision-making, using context or evidence to help a system (or a person) make a better call. My stack is still evolving as I build, and that's just part of the process rather than something to hide.

### 🛠️ Verivo
An AI-powered trust and skill-verification platform for Nigeria's informal skilled-trades market. I've worked on the AI-driven diagnostic interview flow (including voice interaction), a RAG pipeline using Pinecone and Gemini for skill assessment, backend APIs, and the scoring logic behind how trust is calculated. It's the project where I've combined software engineering, AI, and real-world product thinking the most.
